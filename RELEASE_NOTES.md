# R1

First public release of the **Over the Hedge Enhanced PC Patch**.

R1 packages the validated V12A13 cumulative executable and the verified cumulative patcher.

Highlights include modern borderless rendering, modern resolutions through 4K/Desktop, dynamic Hor+ aspect/FOV handling, AF16 and trilinear filtering improvements, DPI awareness, orderly Alt+F4, intro skip, native single-profile auto-selection, and Windows-key restoration.

The native 60 Hz game timing, native FSAA Off/2x/4x behavior, HUD behavior, audio path, save locations, controller hot-plug, and D24S8 depth format are deliberately preserved after audit.
